# Landing Page: Основи кібербезпеки

Простий, адаптивний і семантичний лендинг, присвячений базовим правилам цифрової гігієни та кібербезпеки в інтернеті. Проект розроблений в рамках навчальної або практичної роботи з інформатики.

## Описание проекту
Сайт створений з використанням сучасних стандартів HTML та CSS. Особливу увагу приділено семантичній розмітці (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`), доступності та адаптивному дизайну для мобільних пристроїв і ПК.

##  Основні розділи сайту
- **Головний екран (Hero):** Привітний блок із закликом до дії (CTA).
- **Основні загрози:** Короткий огляд фішингу, шкідливого ПЗ та слабких паролів.
- **Правила безпеки:** Корисні рекомендації щодо захисту особистих даних та акаунтів.

##  Використовувані технології
- **HTML** (семантичні теги)
- **CSS** (Flexbox, Grid, адаптивні медіазапити, змінні)
- **GitHub** (версіонування та розміщення репозиторію)

##  Як запустити проєкт
1. Створіть спільну папку для проєкту
2. Збережіть файли `index.html` та `style.css` в одну папка.
3. Відкрийте файл `index.html` у будь-якому сучасному веб-браузері.
